# Transformer Cellular Automata (TCA)

This repository details my experiments for CS 148 at Caltech on a new class of 
machine learning models: Transformer Cellular Automata.

Inspired by the paper *Growing Neural Cellular Automata* by [Mordvintsev et al](https://distill.pub/2020/growing-ca/), I aim to understand the applicability of a transformer MHA-based differential update rule for modelling complex phenomena. 

The first model system I will be analyzing is the active matter system, working with data from [Thomson Lab](https://thomsonlab.caltech.edu/active-matter/) -- specifically with [Shichen Liu](https://shichenliu.caltech.edu/).
